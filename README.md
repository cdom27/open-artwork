# Open Artwork

Open Artwork is an open art data project for exploring artists, artworks, metadata, images, and color palettes.

The original implementation was built with Express and TypeScript and focused mainly on CRUD operations. The rewrite is an opportunity to build a better experience for content-heavy art data while exploring work that is more meaningful to the project, such as image processing and palette generation.

The web app will use Sveltekit to support server-side rendering and pre-rendering for artist pages, artwork galleries, metadata, palettes, and API documentation. The backend will use Go and Gin, giving the project a natural place to explore CPU-oriented work.

**The previous API is currently offline and will return only when the rewrite is complete.** The new API and data model are still subject to change.
